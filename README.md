# AQA Bio Mastery

A-level AQA Biology (7402) exam-focused revision app: full spec coverage,
key-word glossaries, exam-style questions with model answers, mark schemes,
and common-mistake warnings.

## Stack
- Backend: Node/Express (server/index.js)
- Frontend: static HTML/CSS/JS (public/index.html)
- Database: Supabase (Postgres), read via the public anon key (RLS restricts it to read-only)

## Local run
npm install
npm start
# open http://localhost:3000
